# smoke_v2

Fixed synthetic retrieval questions and relevance labels for software regression tests.
`config.json` binds the query set, relevance labels and knowledge snapshot. Keep these files
together and preserve their identifiers and content hashes.

The suite checks retrieval behavior, source applicability and evidence gaps; it is not a
clinical validation set or a model-selection benchmark. See the
[evaluation overview](../../../docs/evaluation.md) for the current validation scope.
