# CDC supplemental retrieval fixture v1

This fixed engineering fixture covers narrowly reviewed CDC supplemental evidence added to the v6 knowledge snapshot. It checks entity-specific diagnostic test roles and negative-result boundaries, pregnancy testing, contact evaluation, infection-versus-disease education, missed-dose education, treatment adverse-event signals, infectiousness reassessment, return to activities, and home precautions.

The sources have United States jurisdiction and are supplemental to the primary China and WHO evidence. The fixture is not a clinical validation set and must not be used for retriever, model, threshold, chunking, fusion, or reranker selection. Corpus changes require a new recorded generation and fixture version; historical fixtures remain immutable.
